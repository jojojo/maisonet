# Essai de l’interface commune sur iOS 12

Ouvrir `/essai-ipad` sur l’appareil. Cette route active un choix d’affichage dans la session, sans changer les autorisations. La connexion et les écrans React/Inertia habituels sont utilisés, y compris les jeux. Le lien « Version de secours », rendu en HTML sans JavaScript, permet de retrouver la connexion ou le kiosque simplifié si l’essai ne démarre pas. Une déconnexion supprime le choix d’essai. Sans ce choix, les anciens iPad gardent leur redirection vers le kiosque simplifié.

Une seule interface React est compilée pour tous les navigateurs avec une cible Safari/iOS 12. Tailwind 3.4 et PostCSS produisent le CSS commun, sans couches CSS, couleurs OKLCH, `color-mix`, `:is` ou `:where` dans le résultat. Les couleurs personnalisées conservent leurs variables HSL pour les canvas et disposent de canaux RGB pour les utilitaires avec opacité. Les classes d’importance utilisent la syntaxe Tailwind 3. Les styles définis dans les fichiers `.ts` sont inclus dans la détection des classes.

Les polyfills de langage sont chargés avant React et Inertia. Les API ResizeObserver et IntersectionObserver et les abonnements MediaQueryList manquants sont complétés. Les grilles des jeux conservent leurs proportions sans `aspect-ratio` ; les espacements flex et les unités de hauteur récentes ont des solutions de repli. Le helper Ziggy est compilé par Vite plutôt qu’injecté directement par Blade. Les jeux partagent les commandes pointer modernes et un adaptateur touch/mouse pour les anciens appareils. Le dessin des rectangles arrondis ne dépend plus de `CanvasRenderingContext2D.roundRect`.

Vérifications : tests PHP du choix d’affichage et du maintien des protections kiosque, tests JavaScript des commandes tactiles et du canvas, compilation, analyse des sorties JS/CSS, parcours navigateur de la connexion, du tableau de bord, des montagnes, du kiosque et des dix jeux. Les essais navigateur désactivent les API récentes et utilisent de vrais événements tactiles, mais Chrome avec un ancien user-agent ne reproduit pas le moteur Safari 12. Un essai sur l’iPad physique reste nécessaire pour confirmer le rendu, les performances et le fonctionnement des jeux.
